# 市場調査サマリー(クラウドソーシング)

作成: 2026-08-27

## 方針

- CrowdWorks / Lancers 等のクラウドソーシング市場で、Excel 作業が
  現在も人力発注されていることを確認したのが本製品の企画背景。
- 本ファイルは傾向の要約のみを記録する。募集文の大量転載はしない。
  個人・企業を識別できる情報(発注者名・案件 URL・金額の個別値等)は保存しない。

## 確認された作業カテゴリ

現在も人力で発注・受注されていることを確認した作業:

1. **複数 Excel ファイルの統合**
   - 部署別・月別・店舗別に分かれた Workbook を 1 つにまとめる。
2. **大量 Sheet への転記**
   - 数十〜数百 Sheet に同じ形式でデータを転記する。
   - 台帳 → 個票、集計表 → 明細などの反復転記。
3. **CSV 形式変換**
   - Excel → CSV、CSV → Excel の形式変換。文字コード・列順の調整を含む。
4. **CSV から複数 Excel への振り分け**
   - 基幹システム出力の CSV を、キー列で複数の Workbook / Sheet に振り分ける。
5. **重複・空欄・表記揺れの確認**
   - 名寄せ前のチェック、必須項目の空欄確認、全半角・スペース揺れの確認。
6. **毎月同じ Excel 処理**
   - 月次で同一手順の集計・転記・整形が繰り返し発注されている。
7. **Workbook 間の反復転記**
   - 元帳 Workbook から報告用 Workbook への定型転記。

## 示唆

- これらは「高度な Excel 機能」ではなく「大量・反復・確実さ」が価値。
- 発注側は非技術者が多く、マクロ・スクリプト提供型の納品は保守できない。
  → GUI の業務アプリ + ローカル完結が適合する。
- 業務データを外部サービスへアップロードできない(社内規程)ケースが
  発注理由に含まれる。→ 完全オフラインが差別化になる。

## 本製品への反映

- v1 Phase 1〜4 は上記カテゴリ 1〜5 に直接対応(roadmap.md)。
- カテゴリ 6・7(反復・定型)は Phase 5(処理レシピ・履歴)で対応。
- 「壊さない」ことが受注者の最大の注意事項であるため、
  Phase 0(安全解析)を全機能の土台に置く。
