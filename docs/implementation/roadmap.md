## Phase 0: Workbook 安全解析(正式クローズ / 2026-08-28)

- 目的: Excel を書き換える前に、その Workbook を安全に解析できる土台を作る。
- 対象ファイルを絶対に変更しない(読み取り専用、保存処理なし)。
- .xlsx の Drag & Drop / ファイル選択(複数)、Open XML SDK での READ ONLY 解析。
- 取得: ファイル名・フルパス・サイズ・Sheet 数・Sheet 名・使用範囲・
  概算行数・概算列数・解析状態。
- 検出: 数式・結合セル・Drawing・Chart・画像・PivotTable・External Link・
  Sheet 保護・マクロ関連ほか(分類ルール: DECISIONS D-004)。
- ✅ / ⚠ / ✖ 分類を UI で確認可能。UI スレッド非ブロック、失敗隔離。
- Phase 0.1(2026-08-28): self-contained win-x64 配布構成の確立(D-011)、
  UI 目視確認と列切れの最小修正。これをもって Phase 0 を正式クローズ。

## Phase 1: 複数 Excel 統合(1A 完了 / 1B 未着手)

Phase 1 は 2 段階に分割する。**Phase 1A 完了時点で Phase 1 全体は CLOSED にしない。**

### Phase 1A: 表データの縦結合(完了 / 2026-08-28)

- 複数 Workbook の同種の表(Header 付き)を、1 つの**新規** Workbook /
  1 Worksheet(既定名「統合結果」)へ縦方向に結合する。
- 1 Workbook につき 1 つの選択 Worksheet。入力 Workbook へは一切書き込まない。
- Header 名(trim 後)で列を対応付けるため、列順が違っても統合できる。
  出力列順は**明示的に選択した基準シート**の Header 順(1A.1 で明示化。D-013)。
- 実行前に必ず Preview validation を通し、Block が 1 件でもあれば実行不可。
- 「元ファイル」「元シート」metadata 列を先頭に追加可能(初期 ON)。
- 詳細仕様は DECISIONS D-012(Phase 1A Safety Policy / Header ルール /
  出力安全設計 / streaming 方針)、D-013(基準シートの明示・選択)。

#### Phase 1A.1: 基準シートの明示・選択(完了 / 2026-08-28)

- 出力列順の基準にするシートを UI で明示・選択できるようにした小補正。
- Core も基準を明示的な引数で受け取り、不正な基準を Block する。
- Header matching 仕様(D-012)は変更なし。

### Phase 1B: Sheet 集約(1B.1 完了 / 1B.2 未着手)

複数 Workbook の Worksheet を、1 つの新規 Workbook へ複数 Worksheet として
並べる機能。Phase 1A と違い行データは混ぜない。
**Phase 1B.1 完了時点で Phase 1B 全体は CLOSED にしない。**

#### Phase 1B.1: 基本要素を保持した Sheet 集約(完了 / 2026-08-28)

- 1 Workbook から複数 Worksheet を選択でき、新規 Workbook へ集約する。
- 保持: セル値・型・日付(1900/1904)・セル書式(表示形式 / フォント / 塗り /
  罫線 / 配置)・行の高さと非表示・列の幅と非表示・結合セル・ウィンドウ枠固定・
  シート表示状態・シート保護。
- Workbook ごとに独立した Stylesheet を出力へ移植し、StyleIndex を remap する
  (別 Workbook の同じ StyleIndex が衝突しない)。
- シートの表示状態は Visible / Hidden / VeryHidden を区別して保持する(D-015)。
- 保持できない要素(数式・グラフ・図形・画像・テーブル・ピボット・条件付き書式・
  入力規則・コメント・ハイパーリンク・オートフィルター・リッチテキスト・
  印刷設定/ページレイアウト・マクロ・外部リンク)は**黙って削除せず**
  Preview で Block する。シート見出しの色とふりがな情報は Warning で明示(D-015)。
- 出力シート名は決定的に一意化し、編集も可能。出力順は Workbook 追加順 →
  Workbook 内 Sheet 順。
- 出力は新規 .xlsx のみ。temp → 再オープン検証(OpenXmlValidator 含む)→ 確定。
- 詳細仕様は DECISIONS D-014、および補正 D-015(Phase 1B.1.1)。

##### Phase 1B.1.1: 安全性・表示状態補正(完了 / 2026-08-28)

- シート表示状態を Visible / Hidden / VeryHidden の 3 値で正確に保持するようにした。
- 詳細は DECISIONS D-015。

#### Phase 1B.2A: 印刷設定・ページレイアウトの安全な移植(完了 / 2026-08-28)

#### Phase 1B.2B1: ハイパーリンクの安全な移植(完了 / 2026-08-28)

#### Phase 1B.2B2A: 標準の入力規則の安全な移植(完了 / 2026-08-28)

## Phase 2: 複数 Workbook / Sheet への一括変更

既存 Workbook の内容を変える初めての Phase。ただし **Source は書き換えない**。
Source をコピーしてからコピー側だけを最小変更する。

### Phase 2A: 同じセルへの一括入力(完了 / 2026-08-28)

- 複数の .xlsx から複数シートを選び、**共通の 1 セル**へ同じ値を入れる。
- Source と同じフォルダへ `<元の名前>_変更済み.xlsx` を作る。Source は完全不変。
- 変更するのは対象 WorksheetPart だけ。他の Part(styles / sharedStrings /
  chart / drawing / table / theme / rels 等)はバイト単位で不変であることを検証する。
- 値の種類は文字列 / 数値 / 空欄のみ。文字列は InlineString で書き、
  sharedStrings には触れない。
- 既に物理的に存在するセルだけが対象。行やセルの新規作成はしない。
- 数式を含むブック、保護シート、結合セル・入力規則・ハイパーリンク・
  リッチテキストの対象セル、Pivot シート、Validator エラーのある Source は Block。
- 変更内容は Workbook の隣に `<出力名>.xlsx.audit.json` として残す。
- 変更する ZIP entry が対象 WorksheetPart ちょうど 1 件であることをテストで固定した。
- 取り消し(rollback)は best effort。消せなかったファイルが残った場合は、
  「作成していません」と断定せずファイル名で通知する(補正 D-024)。
- 詳細は DECISIONS D-023、および補正 D-024(Phase 2A.1)。

### Phase 2B: 複数セルへの Input Set(完了 / 2026-08-28)

- 「どのセルへ、どんな種類の、どの値を入れるか」の一覧(入力セット)を作り、
  選択したすべてのシートへ 1 回で適用する。B2=確認済み / F8=1500 / H10=空欄 など。
- 同じセルの重複指定は Block。1 セルでも guard に当たれば全体 Block(部分適用なし)。
- Workbook は 1 ファイル 1 回しか開かず、Worksheet の保存も 1 シート 1 回。
  2,000 operations まで実測し、Core に件数上限は設けない。
- 一覧は画面で編集でき、表計算からのタブ区切り 3 列の貼り付けにも対応
  (不正 1 行で全体拒否)。
- 詳細は DECISIONS D-025。

### Phase 2C1: キー一致で 1 行を特定し、決まったセルへ転記(完了 / 2026-08-28)

- データ元(.xlsx / .csv)の表からキーが一致する 1 行を探し、その項目を
  転記先の決まったセルへ入れる。転記先ごとに違う値になる。
- 手入力(2B)とキー一致(2C1)は `ResolvedCellMutation` という共通形に合流し、
  走査・guard・No-op・出力計画・書き込み・検証は 1 つの実装を共有する。
- キーは文字として完全一致のみ(正規化しない)。ちょうど 1 行に一致すること。
- CSV は UTF-8 / CP932 を自動判別。引用符内のカンマ・改行も正しく読む。
- 控えは転記のみ schemaVersion 2(データ元・キー・行番号を残す)。
- 詳細は DECISIONS D-026。

### Phase 2C2: 表同士の行キー突合・既存行更新(完了 / 2026-08-28)

- データ元の表と転記先の表をキーで突合し、既存行の指定列だけを更新する。
  行番号ではなくキーで対応付け、行順が違っていてもよい。
- 両側に存在するキーだけを更新(行の追加・削除なし)。片側だけのキーは
  件数を集計して知らせる。重複キーは更新に使われるなら Block。
- 転記先は項目名の行から列名で解決。1 シート 10 万キー行を実測済み上限とする。
- guard・書き込み・検証は 2B / 2C1 と同じ共通 pipeline を使う。控えは schemaVersion 3。
- 詳細は DECISIONS D-027。

### Phase 2D: 処理設定(レシピ)の保存・再利用 v1(完了 / 2026-08-28)

- タブ 4 / 5 / 6 の設定に名前を付けてこの PC に保存し、次回読み込めるようにした。
- 保存するのはルールだけ。ファイルの絶対パスもファイル名も入れないので、
  毎月ファイル名が変わっても同じ設定を使える。
- 読み込んでも自動実行しない。必ずプレビューをやり直し、既存の安全チェックを通す。
- `%LOCALAPPDATA%` の中だけ・schemaVersion 1・一時ファイル経由の置き換え保存。
- 詳細は DECISIONS D-028。

### Phase 2D.1: 正常実行を根拠にしたレシピ保存(完了 / 2026-08-28)

- 実行して成功したあと、そのままの設定なら処理設定として保存できるようにした。
  作った出力が同じ名前で残っていてもよい。
- 同名衝突を無視したのではない。再実行のときは引き続き Block で、
  実行まわりの安全確認は何も変えていない。
- 判断は「今の設定が、最後に正常終了した実行の設定と完全に同じか」だけ。
  失敗・中止は根拠にしない。控えはメモリ上のみで、閉じれば消える。
- 詳細は DECISIONS D-029。

### Phase 2E: CSV 変換・整形 v1(完了 / 2026-08-28)

- Excel / CSV の表を、別のシステムで使う項目名・並び順の新しい CSV にする。
- 出力する列を 1 件ずつ指定(データ元の列 / 固定値 / 空欄)。改名・並べ替え・
  不要列の除外・同じ列の複数出力・固定値列の追加まで。行は加工しない。
- UTF-8 BOM / UTF-8 / CP932、必要なときだけ / すべて引用符、CRLF。
- 元のファイルは読み取りのみ。上書き禁止で、書いたものを読み直して照合してから確定。
- レシピ(csv-transform)に最初から対応。
- 市場調査により、従来 2E だった検索・置換より先行させた。詳細は DECISIONS D-030。

### Phase 2E.1: 作業用ファイルの所有権(完了 / 2026-08-28)

- CSV 変換の作業用 .tmp を、実行ごとに一意な名前で新規作成するようにした。
- 実行前からあったファイルは上書きせず、取り消しの対象にもしない。
- 取り消しの対象へ登録するのは、新規作成できて所有が確定した直後(書き込みの前)。
- 控えもパスではなくストリームへ書く。詳細は DECISIONS D-031。

### Phase 2F-R: PDF 対応の実現性ベンチマーク(完了 / 2026-08-29)
