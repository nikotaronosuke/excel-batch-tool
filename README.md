# Excel Batch Tool

> **Excel Batch Tool は開発コードネームです。正式な製品名は未定です。**

Windows 上で、複数の Excel Workbook を Microsoft Excel を開くことなく、
**完全ローカル**で安全に一括処理することを目指しているデスクトップアプリです。

**現在は初期開発段階です。** 完成品・安定版ではありません。

## 現在できること

**入力した Excel ファイルは、解析でも統合でも一切変更しません。**

### 1. 読み取り専用の Workbook 解析

Excel ファイルを**書き換える前に安全に把握する**ための解析です。

- `.xlsx` ファイルの Drag & Drop / ファイル選択(複数同時)
- Workbook ごとの情報表示
  - シート数・シート名・使用範囲・概算行数/列数・ファイルサイズ
- 書き換え時に注意が必要な要素の検出
  - 数式 / 結合セル / 図形 / グラフ / 画像 / ピボットテーブル / 外部参照 /
    シート・ブック保護 / テーブル / データ入力規則 / 条件付き書式 /
    コメント / 定義名 / ハイパーリンク / OLE・ActiveX / マクロ関連 など
- 解析結果の分類表示
  - ✅ 通常 / ⚠ 注意が必要 / ✖ 現在非対応

### 2. 表データの縦結合

複数の `.xlsx` に分かれた同じ形の表を、1 つの**新しい** Workbook にまとめます。

- 1 ファイルにつき 1 シートを選んで縦に結合(表の 1 行目を見出しとして扱います)
- 列の順序が違っても、同じ見出し名なら対応付けて結合
- どのシートの見出し順で列を並べるかを「基準」として選択(既定は先頭のシート)
- 実行前のプレビューで、対象数・出力予定行数・出力する列・問題点を確認
  - 見出しの不一致(不足 / 余分)、空の見出し、重複した見出しを事前に検出
  - 数式や結合セルを含むシートは、意味が壊れる可能性があるため対象外として明示
  - 実行できない問題が 1 件でもある間は、作成ボタンを押せません
- 「元ファイル」「元シート」列を先頭に追加可能
- 出力は新規 `.xlsx` のみ。既存ファイルは上書きしません

### 3. シートの集約

複数の `.xlsx` から選んだシートを、1 つの**新しい**ブックにシートとして並べます
(2. と違い、行データは混ぜません)。

- 1 つのブックから複数シートを選択可能。非表示シートは一覧で明示されます
- 保持するもの: セルの値と型、日付、書式(フォント・塗りつぶし・罫線・配置・
  表示形式)、行の高さ / 非表示、列の幅 / 非表示、結合セル、ウィンドウ枠の固定、
  シートの表示状態、シートの保護
- 出力シート名は自動で一意になり、その場で編集もできます
- シートの表示状態は「表示 / 非表示 / 非常に非表示」を区別して引き継ぎます
- 基本的な印刷設定・ページレイアウトも引き継ぎます(余白、印刷オプション、
  用紙・向き・拡大縮小、文字だけのヘッダー/フッター、改ページ位置、
  印刷範囲・印刷タイトル)。**完全再現ではありません**: プリンター固有の設定、
  ヘッダー/フッターの画像、複雑な名前定義を含むシートは対象外として検出します
- 現在のバージョンで保持できない要素(数式、グラフ、図形、画像、テーブル、
  ピボットテーブル、条件付き書式、コメント、
  オートフィルター、リッチテキストなど)を含むシートは、
  **黙って削除せず**プレビューで理由を示して対象外にします
- 一般的な入力規則を保持します(直接指定のプルダウン、同じシート内の範囲を使う
  プルダウン、数値 / 日付 / 時刻 / 文字数の制限)。名前定義や関数を使う入力規則、
  他シートを参照する入力規則、新しい形式(x14)の入力規則、ユーザー設定の数式は
  事前に検出して対象外にします
- Web / メールへのリンクと、集約対象のシートを指すブック内リンクを保持します
  (リンク先へのアクセスは行いません)。ローカルファイルへのリンク、集約対象外の
  シートを指すリンク、複雑な参照は事前に検出して対象外にします
- 出力は新規 `.xlsx` のみ。既存ファイルは上書きしません

> 現在のバージョンはシートの完全なコピーではありません。上記の基本要素だけを
> 引き継ぎます。

## 方針

- **Windows 専用**(.NET 8 / WPF)
- **Microsoft Excel 本体不要**(Office Interop 不使用。
  [Open XML SDK](https://github.com/dotnet/Open-XML-SDK) で直接読み取り)
- **完全ローカル**(クラウドサービス・外部 API・ログイン不使用。
  アプリ自身はネットワーク通信機能を持ちません)
- 対象は `.xlsx`(`.xls` は対象外)

## ビルド

.NET 8 SDK が必要です。

```
dotnet build
dotnet test
dotnet run --project src/ExcelBatchTool.App
```

## 配布用ビルド(self-contained)

配布版は self-contained(.NET Desktop Runtime の別インストール不要)の
Windows x64 構成です。

```
dotnet publish src/ExcelBatchTool.App -c Release -p:PublishProfile=win-x64-self-contained
```

出力: `src/ExcelBatchTool.App/bin/Release/net8.0-windows/win-x64/publish/`
(この中の `ExcelBatchTool.App.exe` を起動)

## 構成

```
src/ExcelBatchTool.Core   … 解析エンジン(読み取り専用)
src/ExcelBatchTool.Core/Merge       … 表の縦結合(検証・ストリーミング読み書き)
src/ExcelBatchTool.Core/Aggregation … シートの集約(検証・書式の移植・出力検証)
src/ExcelBatchTool.App    … WPF デスクトップアプリ
tests/                    … テスト(架空データで生成した Workbook を使用)
```

テストでは、解析・プレビュー・統合の前後でファイルの SHA-256 ハッシュ・サイズ・
最終更新日時を比較し、**入力ファイルを一切変更しないこと**を自動検証しています。
出力側も、生成したファイルを開き直して見出しと行数を検証してから確定するため、
途中で失敗しても壊れた `.xlsx` が残りません。
